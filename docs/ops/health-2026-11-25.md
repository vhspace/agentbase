## Usage

- 401 rejections on /mcp: 1,300–1,500 per day, 19.4k over 14d. Almost all
  monitors and crawlers (FixterMonitoring alone 10.1k). Real-looking clients
  hitting the wall: `node` 435, `coda-agent-runtime` 168, python-httpx/requests 266.
- OAuth funnel since the flip (Nov 8): 23 successful client registrations
  (`coda-agent-runtime`, Chrome/Edge browsers, `node`), 2 GET /authorize 200
  (both UA `node`, Nov 17 and 24), **0 POST /authorize**. The 5 completed
  connects in the week of Nov 8 were the end-to-end test. No human has reached
  the connect page from a browser.
- Authenticated MCP traffic, 30d: claude-code (likely the maintainer's own
  plugin) 715 responses, codex-mcp-client 115, MistralAI-MCPClient 29. They
  initialize and list tools; authenticated tool calls were 5 searches, 5 stores
  and 2 `agentbase_me`, all consistent with the maintainer's own sessions.
- Anonymous tool calls, 30d: 154 introspect, 48 search, 38 `agentbase_setup`
  failures. All setup failures and the 12 search failures came from probes
  (python-requests, BrickBlueBot) and stopped on Nov 9.

## Incidents and gaps recorded for the next repair run

1. **Connect funnel never completes.** Clients register but no browser ever
   loads /authorize. Needs a real-client test (claude.ai custom connector,
   Cursor, Claude Code fresh session) by the owner to tell a client-side stall
   from a server-side one. Until then the 401 flip has produced no accounts.
2. **No alarms.** Zero CloudWatch alarms exist. Minimum useful set: Lambda
   errors > 0 on McpServer/OAuthServer, CloudFront 5xx > 0, a synthetic that
   POSTs /mcp/public tools/list.
3. **`server/discover` returns HTTP 400.** MistralAI-MCPClient and claude-code
   2.1.321 send it; the server answers JSON-RPC -32601 with a 400 status. Check
   whether a 200 body is expected by those clients.
4. **Cost invisible.** Cost Explorer reports $0.00 for October and November
   (credits). No cost baseline is possible from the account.
5. **Log noise.** The OAuth Lambda prints a Node `url.parse()` deprecation at
   ERROR level on every cold start (~70/day) from a dependency, and an AWS SDK
   `userAgentAppId` WARN. Both will mask real errors in a log-based alarm.
6. **Repo hygiene.** No lockfile, so `npm audit` cannot run. Secret scanning is
   disabled on the repository.
7. **401 rejections aren't `MCP response` log lines.** They are `MCP request`
   lines with `rejected = "unauthorized"`; a dashboard filtering on responses
   undercounts traffic by 99%.

Nothing was changed in prd during this check.
